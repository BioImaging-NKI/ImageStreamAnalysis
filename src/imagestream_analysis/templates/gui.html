2IDEAS exports

Add the zip files exported from IDEAS (one folder per dataset). For each zip, set the pixel size and give the channels that are needed a name. Roles go with the marker name and hold for every zip that has a channel of that name. Datasets with the same experiment label are classified together and grouped in the overview. To compare conditions, give each dataset its condition (control, treated, …) and its replicate (the donor or independent experiment it comes from).
